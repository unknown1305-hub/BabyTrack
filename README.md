# BabyTrack Preview

Independent preview copy of the BulkTrack interface. This project uses the `/BabyTrack/` Pages path and `babytrack_` localStorage keys so it does not share app storage with BulkTrack.

**Preview limitation:** meal ingredient names and nutrition values are copied from the source app as placeholders for layout review. They are not baby portion guidance and must be replaced/validated before real use. The adult calorie-surplus prediction is not a valid infant/toddler growth prediction.

Deploy this repository to GitHub Pages using the included GitHub Actions workflow.
